# concordkit/.github

The public profile of the `concordkit` GitHub organisation. GitHub shows `profile/README.md` on the organisation page once this repository is public.

The organisation avatar is the Concord logo, Core's orbit roundel: `mockups/ecosystem-icons/roundel/export/400/core.png` (master `roundel/core.svg`), uploaded by hand in the organisation settings. The profile README carries no logo of its own, since the page header already shows the avatar.
