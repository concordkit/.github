# concordkit/.github

The public profile of the `concordkit` GitHub organisation. GitHub shows `profile/README.md` on the organisation page once this repository is public.

`profile/concord-logo.png` is the Concord logo and the organisation avatar: Core's orbit roundel, copied unchanged from `mockups/ecosystem-icons/roundel/export/400/core.png` (master `roundel/core.svg`). Change it there, then copy it here again.
