# concordkit/.github

The public profile of the `concordkit` GitHub organisation. GitHub shows `profile/README.md` on the organisation page once this repository is public.

The organisation avatar is drawn by `avatar/build-avatar.py` from the Concord orbit mark and the design system's own Atkinson Hyperlegible Next font, converted to outlines. No font file is copied here.

```sh
python3 -I avatar/build-avatar.py
```
