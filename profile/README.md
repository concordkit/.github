# Concord

**One interface. Every input.**

Concord is a family of add-ons for World of Warcraft, built on one shared core. Every add-on looks and behaves the same way, so you learn it once. Each one works fully with keyboard and mouse, gamepad and Steam Controller, and you can move between them freely.

## Add-ons

| Add-on | What it does |
| --- | --- |
| Concord: Core | The foundation every other add-on builds on: one input system, one tooltip service and one settings window |
| Concord: Haggler | Gold-making help for crafting, selling and flips, with prices from AHledger |
| Concord: Provenance | A complete log of every item and every copper you gain or spend, and where it came from |
| Concord: Steam Controller Extras | Features only the Steam Controller can offer, starting with radial menus on the trackpads |

More add-ons are planned, among them bags, action bars and an auction house built for every input.
